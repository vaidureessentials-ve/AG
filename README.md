# VAIDURE 🌿

**Where Nature Feels Luxurious**

Vaidure is a modern, responsive web application for a premium hospitality amenities brand. We specialize in sustainable elegance, providing custom-tailored body care solutions, dry amenities, and wet amenities for modern hotels, resorts, and conscious consumers.

## 🚀 Tech Stack

This project is built using modern web development technologies to ensure maximum performance and maintainability:

*   **Framework:** [React 19](https://react.dev/)
*   **Build Tool:** [Vite](https://vitejs.dev/) (Extremely fast development server and optimized production builds)
*   **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (Utility-first CSS framework for rapid UI development)
*   **Routing:** [React Router v7](https://reactrouter.com/) (Client-side routing)
*   **Icons:** [Lucide React](https://lucide.dev/)

## 🛠️ Local Development Setup

To run this project on your local machine, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

### Installation

1. **Install dependencies:**
   Open your terminal in the root directory of the project and run:
   ```bash
   npm install
   ```

2. **Start the development server:**
   Once the installation is complete, start the Vite development server:
   ```bash
   npm run dev
   ```

3. **View the application:**
   Open your browser and navigate to `http://localhost:5173/` to see the site running locally. The server supports Hot Module Replacement (HMR), so any changes you make to the code will instantly update in the browser.

## 📁 Project Structure

Here is a quick overview of how the codebase is organized:

```text
vaidure/
├── public/                 # Static assets (images, logos) that don't need processing
├── src/                    # Main source code directory
│   ├── assets/             # Component-specific images and graphics
│   ├── components/         # Reusable UI components (Navbar, Footer, ProductCards, Forms)
│   ├── pages/              # Individual page layouts (Home, About, Contact, Product Pages)
│   ├── App.jsx             # Root component handling all application routing
│   ├── index.css           # Global CSS and Tailwind directives
│   └── main.jsx            # Application entry point
├── index.html              # Main HTML template containing SEO and Meta tags
├── package.json            # Project metadata and dependencies
├── tailwind.config.js      # Tailwind CSS configuration and theme overrides
└── vite.config.js          # Vite build configuration
```

## 🌐 SEO & Meta Configuration

The `index.html` file has been optimized for Search Engines (SEO) and social media sharing. It includes:
*   Open Graph tags (for Facebook/LinkedIn sharing)
*   Twitter Card tags
*   JSON-LD Structured Data (Organization schema) to clearly communicate brand details to Google and Bing.
